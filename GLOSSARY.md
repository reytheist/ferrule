# Ferrule

Local-first desktop email client and Pigment Miniatures Show staff collaboration workspace.

## Language

**Launch Splash**:
The frameless startup window shown exclusively on first boot prior to setup while Ferrule initializes, replaced by the main window once ready.
_Avoid_: Loading screen, boot screen, intro screen

**Onboarding**:
The guided first-run setup flow (Appearance, First Account, and optional Pigment Staff Sync) shown when a user has not yet completed setup and has no configured accounts.
_Avoid_: Setup wizard, first-run modal, welcome flow

**Feature Tour**:
The skippable, interactive spotlight walkthrough of the live workspace offered after Onboarding completes and replayable at any time.
_Avoid_: Tutorial, product tour, walkthrough

**Account Space**:
A configured email account represented as a color-coded workspace (`Personal` or `Pigment Staff`) that isolates identities and sharing rules.
_Avoid_: Mailbox, profile, account tab

**Pigment Staff Sync**:
The optional team collaboration connection that syncs shared threads, comments, drafts, show contacts, calendar, and action items with a Pigment Staff server.
_Avoid_: Team sync, staff mode

**Shared Draft**:
A collaborative reply draft attached to a shared Pigment Staff thread that one teammate locks to edit at a time, routes for review and approval, and hands back to the original mailbox owner to send.
_Avoid_: Team email draft, shared compose, group reply

**Action Item**:
A trackable Pigment operations task with status, owner, department, milestone, optional due window, location, and budget note, linkable to an email thread, Meeting Doc, or shared calendar event.
_Avoid_: Todo, ticket, checklist item

**Meeting Doc**:
The shared collaboration workspace attached to a Pigment calendar event, holding its agenda, carried-over tasks from prior recurring meetings, Markdown notes, linked Action Items, and Discord recap.
_Avoid_: Event notes, meeting minutes, calendar note
